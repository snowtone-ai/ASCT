## コードの構造に関する言葉

🔵 **変数 (variable)**
値に名前をつけて入れておく「箱」。`x = 5` なら、`x` という箱に `5` が入る。

🔵 **関数 (function)**
「入力を受け取って、何か処理して、結果を返す」ひとまとまりの手続き。`def 名前(...):` で定義する。
料理のレシピに似ている。材料（入力）→ 調理（処理）→ 料理（返り値）。

🔵 **引数 (argument / parameter)**
関数に渡す「入力」。`load_company_config(1)` の `1` が引数。

🔵 **返り値 / 戻り値 (return value)**
関数が処理の結果として返してくる値。`return` の後ろに書かれる。

🔵 **クラス (class)**
「データ」と「そのデータを扱う関数」をひとまとめにした設計図。`class Event:` のように書く。
たい焼きの「金型」。金型（クラス）から、たい焼き（インスタンス）を何個も作れる。

🔵 **インスタンス / オブジェクト (instance / object)**
クラス（設計図）から実際に作られた「実物」。`event = Event(...)` の `event` がインスタンス。

🔵 **メソッド (method)**
クラスの中にある関数。`db.add(event)` の `add` がメソッド。`データ.動作()` の形。

🔵 **属性 / プロパティ (attribute / property)**
インスタンスが持っているデータ。`event.company_id` の `company_id` が属性。`データ.中身` の形。

🔵 **辞書 (dict)**
「名前：値」のペアを集めたもの。`{"name": "りんご", "price": 100}`。日本語の辞書（単語→意味）と同じ発想。

🔵 **リスト (list)**
値を順番に並べたもの。`[10, 20, 30]`。買い物メモのように順序がある。

🔵 **モジュール / パッケージ (module / package)**
コードを書いたファイル1つが「モジュール」、フォルダにまとめたものが「パッケージ」。

🔵 **import (インポート)**
他のファイルで定義された関数やクラスを「持ってきて使う」宣言。

🔵 **型 / 型ヒント (type / type hint)**
その箱に入る値の種類（数字か、文字か、など）。`name: str` は「name は文字列」という注釈。

## ASCT のドメイン（業務）に関する言葉

🟣 **ASCT (Agentic Supply Chain Twin)**
複数のAIエージェントが協調して、サプライチェーン（供給網）の判断を自動で下すエンジン。

🟣 **イベント (Event)**
「需要が急増した」「輸送路が遮断された」など、システムが反応すべき出来事。すべての処理の起点。

🟣 **エージェント (Agent)**
特定の専門分野を担当する判断モジュール。例：需要予測担当、在庫最適化担当、物流担当、供給リスク担当。

🟣 **シナリオ (Scenario)**
エージェントが提案する「打ち手の候補」と、そのコスト・信頼度をまとめたもの。

🟣 **CEOオーケストレーター (CEO Orchestrator)**
各エージェントが出したシナリオを見比べて、最終的に1つの決定を下す「社長役」のモジュール。

🟣 **エスカレーション (Escalation)**
AIが「自信を持って決められない」とき、人間に判断を委ねること。「上にあげる」の意味。

🟣 **信頼度 (Confidence)**
ある判断にどれだけ自信があるかを 0.0〜1.0 で表した数値。1.0 が最も自信あり。

🟣 **設定 (Config)**
会社ごとの判断基準（予算上限、何を重視するかの重み、など）。`configs/company_1.yaml` に書かれている。

## 技術スタック（道具）に関する言葉

🔵 **FastAPI**
Python で「Web API（外部からの注文を受け付ける窓口）」を作るための道具。

🔵 **API / エンドポイント**
外部とやり取りする窓口。`POST /api/events` のように「住所（URL）」を持つ。

🔵 **ORM (Object-Relational Mapping)**
データベースの表を、Python のクラス／オブジェクトとして扱えるようにする翻訳機。SQL を書かずにDB操作できる。

🔵 **SQLAlchemy**
Python で最もよく使われる ORM ライブラリ。ASCT もこれを使っている。

🔵 **モデル (Model)**
ORM で、データベースの1つの表に対応する Python クラス。`class Event` は `events` 表に対応。

🔵 **セッション (Session)**
データベースとの「会話の窓口」。`db.add()` `db.commit()` などはこのセッションに対して行う。

🔵 **SQL**
データベースに「これを取ってきて」「これを保存して」と命じるための専用言語。

🔵 **Alembic**
データベースの表の構造（スキーマ）を変更・管理する道具。

🔵 **SQLite**
ファイル1個（`asct.db`）で完結する軽量データベース。ASCT の開発用に使われている。

🔵 **Streamlit**
Python だけで簡単な画面（ダッシュボード）を作る道具。ASCT の `dashboard.py` で使用。
