# 1-1 変数と型 — 値に名前をつける

> このレッスンのゴール：コードに出てくる `x = 5` のような行が「何をしているか」分かるようになる。

---

## 🔵 変数 = 値を入れる「ラベル付きの箱」

プログラムは、計算した結果や受け取ったデータを、後で使うために「箱」にしまいます。
その箱に名前（ラベル）をつけたものが **変数** です。

```python
price = 100          # 🔵 price という箱に 100 を入れる
name = "りんご"       # 🔵 name という箱に「りんご」という文字を入れる
total = price * 3    # 🔵 計算結果(300)を total という箱に入れる
```

🔴 **読み方の鉄則**：`=` は「等しい」ではなく「**右の値を左の箱に入れる**」という意味です。
数学の `=` とは違います。`price = 100` は「price に 100 を入れろ」という命令です。

---

## 🔵 型 = 箱に入っている「値の種類」

値にはいくつか種類（**型**）があります。最初は次の4つだけ覚えれば十分です。

| 型の名前 | 何を表すか | 例 |
|---|---|---|
| `int`（整数） | 小数点のない数 | `100`, `-5`, `0` |
| `float`（浮動小数点数） | 小数点のある数 | `0.95`, `1500.0`, `3.14` |
| `str`（文字列） | 文字・文章。**必ずクオートで囲む** | `"りんご"`, `"demand_spike"` |
| `bool`（真偽値） | 「はい/いいえ」の2択 | `True`, `False` |

🟡 **注意**：`"100"`（クオート付き）と `100`（クオートなし）は別物です。
前者は「文字としての100」、後者は「数としての100」。計算に使えるのは後者だけです。
AIコードのバグでよくあるのが、この2つの取り違えです。

## 🟢 ASCT の本物のコードで見る

`src/orchestrator/confidence.py` の中にこんな行があります（13〜14行目）：

```python
half_life_hours = confidence_config["staleness_half_life_hours"]  # 🔵 設定値を箱に取り出す
staleness_factor = 0.5 ** (data_age_hours / half_life_hours)      # 🟢 計算結果を箱に入れる
```

**1行ずつ読む**：
- 1行目：`confidence_config` という設定の中から `staleness_half_life_hours`（古さの半減期＝12時間）を
  取り出して、`half_life_hours` という短い名前の箱に入れ直しています。長い名前を毎回書くのは大変なので、使いやすい名前に置き換えているだけです。
- 2行目：`0.5  の (経過時間 ÷ 半減期) 乗` を計算し、`staleness_factor`（古さによる減点率）に入れています。
  `**` は「べき乗」、`/` は「割り算」です。

🟣 **実務での意味**：これは「データが古いほど信頼度を下げる」計算です。
食品の在庫データは12時間で価値が半分になる、というルールをコードにした部分。
あなたが企画した「鮮度が判断に効く」という思想が、まさにこの1行に宿っています。

## ✅ 検証ポイント（AIコードを読むとき）

AIが書いた変数まわりのコードを読むときは、次を確認します：

- ✅ **名前と中身が合っているか**：`price` という箱に名前の文字列が入っていたら怪しい。
- ✅ **型が合っているか**：数として計算したいのに `"100"` と文字列になっていないか。
- ✅ **`=`（代入）と `==`（比較）の取り違え**：`if x = 5:` はバグ（`==` が正しい）。次のレッスン以降で詳しく。
