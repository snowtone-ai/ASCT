1-1 変数と型 — 値に名前をつける

このレッスンのゴール：コードに出てくる x = 5 のような行が「何をしているか」分かるようになる。

🔵 変数 = 値を入れる「ラベル付きの箱」

プログラムは、計算した結果や受け取ったデータを、後で使うために「箱」にしまいます。 その箱に名前（ラベル）をつけたものが 変数 です。

pythonprice = 100          # 🔵 price という箱に 100 を入れる
name = "りんご"       # 🔵 name という箱に「りんご」という文字を入れる
total = price * 3    # 🔵 計算結果(300)を total という箱に入れる

重要読み方の鉄則：= は「等しい」ではなく「右の値を左の箱に入れる」という意味です。 数学の = とは違います。price = 100 は「price に 100 を入れろ」という命令です。

🔵 型 = 箱に入っている「値の種類」

値にはいくつか種類（型）があります。最初は次の4つだけ覚えれば十分です。

型の名前何を表すか例
int（整数）小数点のない数100, -5, 0
float（浮動小数点数）小数点のある数0.95, 1500.0, 3.14
str（文字列）文字・文章。必ずクオートで囲む"りんご", "demand_spike"
bool（真偽値）「はい/いいえ」の2択True, False

注意注意："100"（クオート付き）と 100（クオートなし）は別物です。 前者は「文字としての100」、後者は「数としての100」。計算に使えるのは後者だけです。 AIコードのバグでよくあるのが、この2つの取り違えです。

✅ 検証ポイント（AIコードを読むとき）

AIが書いた変数まわりのコードを読むときは、次を確認します：

  • 検証名前と中身が合っているか：price という箱に名前の文字列が入っていたら怪しい。
  • 検証型が合っているか：数として計算したいのに "100" と文字列になっていないか。
  • 検証=（代入）と ==（比較）の取り違え：if x = 5: はバグ（== が正しい）。次のレッスン以降で詳しく。
