1-5 クラス — データと処理をひとまとめにした設計図

このレッスンのゴール：class 〜: が出てきたとき「これは設計図だ」と分かり、

何か.属性 や 何か.メソッド() の形が読めるようになる。

🔵 クラス = 「たい焼きの金型」

クラスは 設計図（金型） です。金型そのものは食べられません。 金型から作った たい焼き（インスタンス） が実物です。1つの金型から何個でも作れます。

pythonclass Dog:                        # 🔵 「犬」という設計図
    def __init__(self, name):     # 🔵 作るときに呼ばれる初期設定。nameを受け取る
        self.name = name          # 🔵 この犬の名前を覚えておく（属性）

    def bark(self):               # 🔵 この犬ができる動作（メソッド）
        return self.name + "がワン!"

使う（インスタンスを作る）と：

pythonpochi = Dog("ポチ")     # 🟢 金型から「ポチ」という実物を作る
pochi.name              # → "ポチ"     （属性：データを取り出す）
pochi.bark()            # → "ポチがワン!" （メソッド：動作させる）

重要3つの専門用語を結びつける：

  • クラス … 設計図（class Dog）
  • インスタンス／オブジェクト … 設計図から作った実物（pochi）
  • self … 「その実物自身」を指す。メソッドの中で自分の属性を触るのに使う

注意.（ドット）の読み方：pochi.name は「ポチ の 名前」、pochi.bark() は「ポチ が 吠える」。 ドットは『の』『が』 と読むと自然です。 カッコ () が付いていれば動作（メソッド）、付いていなければデータ（属性）。

⚪ 補足：__init__ という名前

__init__（アンダースコア2個ずつ）は特別な名前で、「インスタンスを作る瞬間に自動で呼ばれる関数」です。 「初期設定（initialize）」の略。RunComposer(session) と書くと、この __init__ が裏で動きます。 最初は「作るときの準備係」とだけ覚えれば十分です。
