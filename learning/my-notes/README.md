# 📓 my-notes — あなた専用の書き込みフォルダ

このフォルダの中のファイルは **あなたが自由に書き込むため** のものです。
教材（`01`〜`04`）は「読む」もの、ここは「書く」もの。役割が逆です。

> 🔴 ここに何を書いても、教材やプロダクト本体には一切影響しません。安心して落書きしてOK。
> むしろ「自分の言葉で書き直す」ことが、読解力を定着させる一番の近道です。

---

## 3つのノートの使い分け

| ファイル | いつ書く | 何を書く |
|---|---|---|
| `learning-journal.md` | 学習の終わりに | 今日読んだ所・分かったこと・つまずき（学習日記） |
| `questions.md` | 疑問が湧いた瞬間 | 「これ何で？」を書き溜める。後でClaudeに聞く |
| `my-words.md` | 新しい言葉に出会ったら | 用語を**自分の言葉で**言い換えてメモ（自分専用の用語集） |

---

## 🟣 おすすめの使い方

- レッスンの「🧠 理解チェック」の答えを、まず `learning-journal.md` に自分で書いてから、
  Claude に答え合わせを頼む。
- 分からない言葉は、`glossary.md`（教材の用語集）を見たうえで、
  **自分の言葉に翻訳して** `my-words.md` に書く。人の説明を写すより、自分の言葉にする方が10倍残ります。
- 疑問は溜めてOK。`questions.md` に書いておき、次のセッションの最初に
  「questions.md に溜めた質問に答えて」とClaudeに頼むと効率的です。

それぞれのファイルに、書き方の例（テンプレート）を入れてあります。上書きして使ってください。
