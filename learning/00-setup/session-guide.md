# 学習セッションの始め方・中断・再開ガイド

このコースは「いつ中断しても、いつでも再開できる」ように設計されています。
そのための運用ルールをまとめます。難しくありません。

---

## 🔴 学習には「2つのモード」がある

| モード | いつ使う | 起動コマンド | できること |
|---|---|---|---|
| 📖 **読む日** | 教材を読む・コードを眺める・質問する | `claude --permission-mode plan` | 読む・質問するだけ。**変更は一切できない**（＝安全） |
| ✏️ **書く日** | progress.md にチェックを入れる・メモを書く・実験する | `claude`（通常起動） | 変更もできる。ただし変更前に確認される |

🔵 **なぜ分けるの？**：初学者のうちは「うっかりコードを壊す」のが一番怖い不安です。
「読む日」モードでは Claude も自分も **ファイルを変更できない** ので、
心置きなくコードを読み回れます。ブレーキの効いた状態で運転する、と考えてください。

> 🟣 **使い分けの例**：
> - 「今日は `3-6` のエージェントをじっくり読みたいだけ」→ **読む日**（`plan`モード）
> - 「`progress.md` にチェックを入れて、ちょっと実験もしたい」→ **書く日**（通常起動）

---

## 📅 毎回の学習の始め方（4ステップ）

PowerShell を開いて、上から順に：

### 1. プロジェクトフォルダへ移動
```powershell
cd C:\Users\chidj\project\ASCT
```

### 2. 仮想環境を有効化
```powershell
.venv\Scripts\Activate.ps1
```
行頭に `(.venv)` が出ればOK。

### 3. 学習用ブランチにいるか確認
```powershell
git branch
```
`* learning` に `*` がついていればOK。もし `* main` だったら：
```powershell
git checkout learning
```

### 4. Claude を起動
```powershell
# 読むだけの日：
claude --permission-mode plan

# 書く日：
claude
```

---

## 🟢 セッションを始めたら最初にやること

Claude に、次のように話しかけてください（コピペでOK）：

```
learning/progress.md を読んで、私が次にやるべき項目を教えて。
```

すると Claude が進捗を見て、「前回は 3-3 まで終わっています。次は 3-4 です」のように案内します。
そのまま「では 3-4 を一緒に読みたい」と続ければ、学習を再開できます。

---

## ⏸️ セッションを中断するとき

区切りのいいところで、Claude にこう頼んでください：

```
今日はここまで。progress.md のチェックを更新して、メモ欄に今日やったことを1行書いて。
```

（「書く日」モードなら Claude が更新を提案します。「読む日」モードのときは、
自分で `progress.md` を開いてチェックを入れてください。）

> 🔴 **大事な習慣**：`progress.md` のメモ欄に「次にやること」「分からなかったこと」を
> 1行残すだけで、次回の再開が劇的に楽になります。未来の自分への手紙です。

---

## ▶️ セッションを再開するとき

上の「毎回の学習の始め方」と同じ手順で起動し、
`progress.md` を読ませれば、続きから始まります。
**前回の記憶が消えていても大丈夫** なように、進捗はすべてファイルに書いてあります。

## ❓ よくある質問

🟡 **Q. `(.venv)` の有効化を忘れて読み始めてしまった**
A. 「読むだけ」なら問題ありません。ただしコードを実際に動かす（サーバー起動など）ときは
有効化が必要です。気づいたらステップ2をやればOK。

🟡 **Q. 間違って main ブランチで作業してしまった**
A. 落ち着いて Claude に「main にいるみたい、learning に戻して」と頼んでください。
このコースの作業はすべて `learning` ブランチの中で行います。

⚪ **Q. VSCode で学習したい**
A. とても良い選択です。次の拡張機能を入れると快適になります：
- **Python**（Microsoft製）— コードに色がつき、定義へジャンプできる
- **Pylance** — 型のヒントを表示してくれる
- **SQLite Viewer** — `asct.db` の中身を表のまま見られる

VSCode のターミナル（`Ctrl + @`）でも上の起動手順は同じように使えます。
Python インタープリタは `.venv\Scripts\python.exe` を選んでください
（`Ctrl+Shift+P` →「Python: Select Interpreter」）。
