# ASCT 読解学習コース — まずここを読む

ようこそ。このフォルダは、プログラミング初学者（文系・非エンジニア）が
**「AIが書いた Python / SQL コードを、自力で読んで検証できる」** ようになるための教科書です。

教材はすべて、あなたが企画した実在のプロダクト **ASCT (Agentic Supply Chain Twin)** の
ソースコードを題材にしています。架空のサンプルではなく、本物のコードを読みます。

---

## 🎯 このコースのゴール

| できるようになること | できなくてもよいこと |
|---|---|
| AIが生成したコードを読んで「何をしているか」説明できる | ゼロからコードを書く |
| 「このコードは正しいか？」を自分で確かめられる | 高度なアルゴリズムを設計する |
| 専門用語をAIとの会話で正しく使える | フレームワークを暗記する |

> 🔴 **重要**：このコースは「書く」ためではなく「**読んで見抜く**」ための訓練です。
> だから各レッスンには「✅ 検証ポイント」（AIコードの間違いを見つけるコツ）が必ず付いています。

---

## 🎨 色分けルール（全ファイル共通）

文章中に出てくる絵文字は、内容の種類を表す信号です。意味を覚えておくと読みやすくなります。

| 記号 | 意味 | 何のため |
|---|---|---|
| 🔵 **概念** | 用語・考え方の説明 | 「これは何？」を理解する |
| 🟢 **コード** | 実際のソースコードを読む箇所 | 本物のコードに触れる |
| 🟡 **注意** | つまずきポイント・誤解しやすい所 | ハマらないため |
| 🔴 **重要** | 必ず覚えてほしい核心 | ここだけは落とさない |
| 🟣 **実務** | 現実のどんな場面で使うかの具体例 | 記憶に定着させる |
| ✅ **検証** | AIコードを読むときのチェック観点 | 間違いを見抜く |
| ⚪ **補足** | あれば便利な周辺知識（飛ばしてもOK） | 余裕があるとき |

### ソースコードの色分け

コードを読むときは、**コードの中にコメントで色マークを差し込んで** 解説します。
`#` で始まる部分は Python の「コメント」（実行されないメモ書き）です。元のコードにはありません。学習用の補助線です。

```python
event = Event(                       # 🔵 Event という「箱」を新しく作る
    event_type=EventType("demand_spike"),  # 🟢 イベントの種類を指定
    company_id=payload["company_id"],      # 🟡 ここが無いとエラーになる（必須）
)
db.add(event)                        # 🔴 ここで初めてDBに登録される
```

さらに重要なコード行は、ブロックの下で「1行ずつの逐次解説」もつけます。

## 🤖 Claude（AI）との付き合い方

このコースを進めるとき、Claude はあなたの **先生** です。代わりに作業する人ではありません。

- 分からない用語が出たら「`3-6` の `policy` って何のこと？」のように、**ファイル番号付きで質問** すると正確に答えてくれます。
- 「このコードの〇行目、なぜこう書くの？」と聞けば解説してくれます。
- 自分の理解が合っているか、「これはこういう意味で合ってる？」と確認に使うのが一番効果的です。
